# Brain MRI Tumor Segmentation and Analysis Using Deep Learning

An end-to-end deep learning system for automated brain tumor segmentation from MRI scans, featuring:
- U-Net / U-Net++ based segmentation
- Explainable AI (Grad-CAM) visualizations
- Interactive 3D tumor visualization
- Streamlit-based clinical UI
- Automated PDF report generation

**Status:** 🚧 Work in progress — Milestone 1 (project setup) complete.

## Tech Stack
PyTorch, MONAI-style preprocessing, Streamlit, Plotly/VTK, ReportLab/FPDF

## Project Structure
See `src/` for core ML pipeline, `app/` for the user-facing application.
